# COMPLETAR  
Comparando sus conocimientos antes de hacer la práctica con sus conocimientos después de hacer la tarea, explicar los principales aprendizajes logrados para beneficio de su formación profesional.  
Si solucionó un problema presentado o utilizó otros comandos que no se mencionan al realizar la práctica también se debe documentar.


Durante esta práctica aprendí cómo los contenedores en Docker se pueden conectar entre sí para trabajar con diferentes servicios. Con los bind mounts pude entender que se puede conectar una carpeta de mi computador con una del contenedor y que los archivos se mantienen en el host aunque se elimine el contenedor. También aprendí a utilizar los volúmenes nombrados que permiten guardar información de forma persistente y administrarla mediante un nombre, y los volúmenes anónimos que Docker crea automáticamente. Durante el proceso tuve problemas con los puertos ocupados, pero pude solucionarlos utilizando otro puerto.
